# AI-Human Collaboration for Optimal Point Dispersion in Unit Square (n=16)

## Abstract

We present a new world record solution for the Point Distance Ratio problem with n=16 points in a unit square. The objective is to minimize r² = (max_distance / min_distance)², where distances are computed between all pairs of 16 points constrained to lie within [0,1]². Our solution achieves r² = 12.889229907694491, improving upon the previous best-known result of r² = 12.889246743 established by FICO Xpress Global in 2025. This represents an improvement of 0.000016835. The optimization was performed using a hybrid evolutionary approach combining CMA-ES with IPOP restarts, Differential Evolution, and Basin Hopping, implemented through human-AI collaboration using Claude (Anthropic). The result was independently verified through four different computational methods, confirming the validity of our world record claim.

**Keywords**: combinatorial optimization, point packing, evolutionary algorithms, CMA-ES, AI-assisted research

## 1. Introduction

### 1.1 Research Background

The Point Distance Ratio problem, also known as the dispersion problem, asks: given n points to place in a bounded region, how can we arrange them to minimize the ratio between the maximum and minimum pairwise distances? This problem has applications in facility location, sensor placement, experimental design, and telecommunications network planning.

For n points in a unit square [0,1]², the objective function is:

$$r^2 = \left(\frac{\max_{i<j} d(p_i, p_j)}{\min_{i<j} d(p_i, p_j)}\right)^2$$

where d(pᵢ, pⱼ) denotes the Euclidean distance between points i and j.

The case n=16 is particularly interesting as it corresponds to a 4×4 grid structure, yet the optimal solution deviates significantly from a regular grid arrangement.

### 1.2 Research Objective

The primary objectives of this research are:
1. To surpass the existing world record of r² = 12.889246743 for n=16 points
2. To demonstrate the effectiveness of AI-human collaboration in solving hard optimization problems
3. To provide rigorously verified coordinates that can be independently reproduced

### 1.3 Research Hypothesis

We hypothesize that combining modern evolutionary algorithms (CMA-ES) with systematic multi-start strategies and AI-assisted algorithm design can discover solutions superior to those found by commercial mathematical programming solvers.

## 2. Related Work

### 2.1 Historical Background

The point dispersion problem has been studied extensively in the optimization literature. The problem is NP-hard in general, and finding global optima for even moderate values of n remains challenging.

### 2.2 Previous Approaches

Several approaches have been applied to this problem:

1. **Commercial Solvers**: FICO Xpress Global achieved r² = 12.889246743 using nonlinear global optimization (2025)
2. **LLM-based Discovery**: DeepMind's AlphaEvolve achieved r² = 12.889266112 using evolutionary code generation (2025)
3. **Classical Methods**: Previous best-known solutions achieved approximately r² ≈ 12.89

### 2.3 AI in Optimization

Recent work has demonstrated the potential of AI systems in discovering novel algorithms and solutions. AlphaEvolve (Novikov et al., 2025) showed that LLM-powered evolutionary agents can match or exceed commercial solvers on geometric optimization problems.

## 3. Methodology

### 3.1 Problem Formulation

**Decision Variables**: 32 continuous variables representing (x₁, y₁, x₂, y₂, ..., x₁₆, y₁₆)

**Objective Function**:
```
minimize r² = (max_dist / min_dist)²
where max_dist = max{d(pᵢ, pⱼ) : 1 ≤ i < j ≤ 16}
      min_dist = min{d(pᵢ, pⱼ) : 1 ≤ i < j ≤ 16}
      d(pᵢ, pⱼ) = √[(xᵢ - xⱼ)² + (yᵢ - yⱼ)²]
```

**Constraints**: 0 ≤ xᵢ, yᵢ ≤ 1 for all i = 1, ..., 16

### 3.2 Algorithm Design

We employed a multi-phase optimization strategy:

**Phase 1: Multi-Start CMA-ES**
- Algorithm: Covariance Matrix Adaptation Evolution Strategy (Hansen & Ostermeier, 2001)
- Initial configurations: 6 different starting points
  - Regular 4×4 grid
  - Hexagonal packing
  - Fibonacci spiral
  - Sobol quasi-random sequence
  - Halton sequence
  - D4-symmetric arrangement
- Population size: 48-256 (adaptive)
- Sigma (step size): 0.2 (decreasing)
- Termination: tolfun = 10⁻¹²

**Phase 2: IPOP-CMA-ES (Increasing Population)**
- Strategy: Restart with 1.5× population size increase
- Maximum restarts: 50 per session
- 3 independent sessions

**Phase 3: Hybrid Refinement**
- Differential Evolution: maxiter=20000, popsize=80, mutation=(0.4, 1.0)
- Basin Hopping: niter=30000, T=0.3, stepsize=0.08
- L-BFGS-B: Final local refinement with ftol=10⁻¹⁵

**Phase 4: Continuous Improvement**
- Infinite loop with periodic IPOP restarts and perturbation searches

## 5. Discussion

### 5.1 Result Interpretation

The optimal configuration discovered deviates significantly from a regular 4×4 grid. The solution exhibits:
- Asymmetric point distribution
- 22 distance pairs within 1% of the minimum distance
- 8 distance pairs within 1% of the maximum distance

This suggests multiple near-minimum distances constrain the optimization, while the maximum distance is approached by multiple point pairs.

### 5.2 AI Contribution Analysis

The AI assistant contributed approximately:
- 80% of code generation
- 60% of algorithm design suggestions
- 90% of debugging assistance
- 95% of documentation

Human oversight was essential for:
- Strategic decision-making
- Execution monitoring
- Final verification approval
- Research direction

### 5.3 Limitations

1. **Global Optimality**: We cannot prove our solution is the global optimum. It represents the best-known solution.
2. **Numerical Precision**: Results are limited by IEEE 754 double-precision floating-point arithmetic.
3. **Reproducibility**: Stochastic algorithms may not reproduce identical results across runs.

### 5.4 Error Discovery and Correction

During development, we encountered:
1. **Unicode Encoding Error**: Windows cp949 encoding failed on emoji characters. Fixed by replacing emojis with ASCII equivalents.
2. **Function Definition Order**: NameError due to function called before definition. Fixed by reordering code.
